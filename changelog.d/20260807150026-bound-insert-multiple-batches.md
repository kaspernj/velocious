- `Record.insertMultiple` now splits large batches into multiple `INSERT ... VALUES` statements bounded by both a configurable `maxRowsPerInsert` row count (default 500) and a configurable `maxInsertSqlBytes` serialized SQL size (default 1 MiB). Callers that need all-or-nothing semantics must wrap the call in a transaction; outside a transaction each chunk commits independently and a failure leaves earlier chunks persisted.
