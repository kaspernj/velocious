Compute the `Content-Length` of string HTTP client request bodies with Node's native `Buffer.byteLength(body, "utf8")` instead of encoding the whole body into a throwaway buffer purely to measure it, keeping the exact UTF-8 byte length (including multi-byte, astral-plane, and malformed UTF-16 surrogate sequences) unchanged, and read the byte length of `Buffer`/`Uint8Array` bodies directly without copying.
