- Quick search is now a declarative `FrontendModelBaseResource` feature: `static quickSearchColumns` (root column names or `{path, column}` pairs for joined relationship paths) expands an index search on the pseudo-column `quickSearch` into an OR of driver-quoted LIKE conditions, and `static quickSearchNumericColumns` adds exact `=` conditions when the trimmed value is a safe non-negative integer. Invalid payloads raise a client-safe `invalid-quick-search` error; owners with an established public error contract override `quickSearchErrorLabel()` / `quickSearchErrorCode()`. `SyncResourceBase` keeps its `Sync quick search` / `sync-invalid-quick-search` contract and now inherits the mechanism instead of implementing it, so app resources no longer need hand-rolled index-search overrides for quick search.
