Add `route.catchAll(...)` to the routes DSL: applications declare their own catch-all controller/action (`route.catchAll({controller: "errors", action: "notFound"})`) instead of hand-wiring `routeResolverHooks` to serve custom 404 responses (for example a JSON error envelope). The resolver applies the declared catch-all only when no route in the tree matched, resolves the controller/action through the standard controller lookup, skips tenant/ability/connection resolution like the built-in not-found path, and keeps the built-in `errors#notFound` response when no catch-all is declared. `route.catchAll()` throws when declared more than once. Covered by `spec/routes/catch-all-spec.js` and documented in `docs/route-catch-all.md`.
