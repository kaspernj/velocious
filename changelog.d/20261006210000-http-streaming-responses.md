- Add a streaming (chunked) response API to the HTTP server: `response.stream()` opens a live chunked response, `response.write()` emits chunks to the client as they are produced, and `response.end()` terminates the stream; `response.isStreaming()`, `response.isStreamAborted()`, and `response.onStreamClose()` let a handler coordinate long-lived responses (e.g. SSE relays) and release resources when the client disconnects.
- Streaming responses share the existing buffered-response lifecycle: headers are emitted immediately with `Transfer-Encoding: chunked`, chunks flow through the same ordered client delivery queue and abort settlement as file responses, malformed use (streaming after a buffered body, or after the stream ended) fails the request, and both in-process and worker-thread handler modes support the API. Buffered responses are unchanged.
