Reusable test tenant-database pools and first-class tenant-cleanup registration in the test harness (STC-135 Task D).

- Added `testTenantPools` configuration: opt-in pools of N pre-provisioned tenant databases per tenant database identifier. `testArgs.acquireTestTenant({databaseIdentifier?, tenant?})` leases a member deterministically (first free in configured order); between tests the member is reset with truncate + migration-ledger baseline instead of create + full structure load + drop, and leases are released automatically at attempt end. Pool exhaustion fails loudly instead of queueing; concurrent acquisitions can never double-lease one member; a failed reset re-provisions the member before it is freed; pool databases are dropped once at run teardown (including the signal/interrupt path). Default provisioning runs the provider's `createDatabase` hook (or framework default), loads the captured default-database `structureSql()` via `StructureSqlLoader` (SchemaCloner fallback per table), and baselines the tenant ledger; `provisionTenant`/`resetTenant` overrides cover app-specific tenant schemas.
- Added `testArgs.registerTenantForCleanup({databaseIdentifier, tenant})`: framework-owned end-of-attempt tenant-database drop through the provider's `dropDatabase` hook (or framework default), so consuming apps (TensorBuzz `backend/src/config/testing.js`) no longer hand-roll Map/afterEach bookkeeping for DDL a test transaction cannot roll back. Non-tenant identifiers fail loudly; drops run even when an earlier one failed and errors are surfaced, never swallowed.
- Existing per-test create/drop provisioning stays the default; the pool is strictly opt-in and `acquireTestTenant` is only meaningful with `testTenantPools` configured.
- Docs: new `docs/test-tenant-pools.md`, README feature entry, and a pointer section in `docs/testing-guidelines.md`.
- Specs: `spec/testing/test-tenant-database-pool-spec.js` (provisioning, isolation, exhaustion, pinning, teardown, reset-failure re-provisioning, concurrent acquisition) and `spec/testing/test-runner-tenant-pool-spec.js` (lease reuse across attempts, committed-row truncation proof, exhaustion failure reporting, cleanup registration ordering/validation).
