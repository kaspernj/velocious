Persist V2 websocket channel broadcast params in the replay event log (sanitized through the channel class's `replayableBroadcastParams` hook) and scope `lastEventId` replay to each subscription's own stream: the checkpoint event must belong to the subscriber's stream, and replay only re-delivers events whose persisted params pass the subscription's `matches()` — the same routing decision live delivery uses. A checkpoint that is missing, expired, or from a different stream reports `channel-replay-gap` and the subscription continues with live delivery, in contrast to the legacy V1 path, which rejects the subscription on `replay-gap`.
