## Added

- `serveFile(response, root, name, options)` in `velocious/build/src/http-server/client/serve-file.js`: a proxy-safe static-asset helper that resolves `name` inside `root` (rejecting path traversal and symlink/`..` escapes), reads the file with `node:fs/promises`, and emits it through `response.setBody` — a length-determined body with a correct `Content-Length`, never `Transfer-Encoding: chunked`. Missing, escaped, or non-file paths return `false` after setting a `404`, so the caller can supply its own error body. Options: `contentType` (default `application/octet-stream`) and `cacheControl` (default `no-store`). This is the framework home for the pattern the fleet console previously re-implemented per app, and the correct replacement for the chunked `response.stream()` path that hangs behind the Rollbridge proxy.
